## Strategy recovered from Fairuz — adapted, not copied
Use the Fairuz process as a method, never as a visual template:
1. Audit the strengths already present.
2. Research sector and real user problems.
3. Define the user journey and commercial friction.
4. Solve missing practical information before adding decoration.
5. Benchmark strong references without imitation.
6. Write conversion-aware copy.
7. Translate into art direction using the existing SEZIONE identity.
8. Build high-fidelity desktop/mobile.
9. Stop for Manuel visual approval.
10. Only then implement, run visual-fidelity QA and technical QA.

### Fairuz principles locked for SEZIONE
- Preserve the approved SEZIONE visual language instead of replacing it.
- Real/approved imagery first; generated imagery only when a genuine content gap requires it.
- No fake reviews, prices, staff credentials, offers or operational claims.
- Typography, spacing and palette quality before extra effects.
- Dependable interaction before decorative complexity.
- Mobile is reviewed as its own designed experience.
