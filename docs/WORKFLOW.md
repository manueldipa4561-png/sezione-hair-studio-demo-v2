# SEZIONE v2 — Micro-Gate Workflow

The process is intentionally split into small recoverable units so long chat sessions are not required.

## Loop
1. Recover latest checkpoint.
2. Verify repository and Notion state.
3. Activate the minimum specialist pod.
4. Execute one bounded deliverable.
5. Verify the deliverable.
6. Write a checkpoint.
7. Continue automatically unless a founder gate is reached.

## Page lifecycle
G0 Locked direction recovery  
G1 Sector / problem / visual / copy research  
G2 Page visual concept  
G3 High-fidelity Figma desktop + mobile  
FA Founder Visual Approval  
G4 Implementation Contract  
G5 Frontend build  
G6 Figma ↔ browser fidelity review  
G7 Technical QA  
FB Founder Implementation Approval  
LOCK Page locked

## Automation principle
Automate deterministic/repetitive work. Use AI/ML as reviewer/accelerator. Keep final art direction and founder approval human.

## Build Pod lock
No UI/frontend implementation before FA.
