## Founder reset
The previous implementation is preserved only as archive/reference. It is not the current approved creative direction.

## Hard production sequence
REFERENCE SELECTION → REFERENCE CARD → ONE PAGE/CONTENT PIECE → FOUNDER REVIEW → BUILD → QA → LOCK → NEXT.

## Primary-reference rule
Every page or major content piece must begin with ONE real high-end website selected as the primary visual reference.

Before design starts, document:
- exact reference URL
- palette logic
- typography logic
- image treatment
- spacing/density
- grid and section rhythm
- navigation/CTA behavior
- mobile behavior
- elements to adapt
- elements not to copy literally

Secondary references are allowed only for named sub-problems.

## Image/content sourcing
Do not generate imagery by default.

Priority:
1. client-owned authentic imagery
2. real public imagery as research/reference/base material
3. properly licensed imagery
4. generated imagery only when there is a genuine gap

For any final commercial publication, rights/licensing must be confirmed or the reference image replaced.
